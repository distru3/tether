# Packaging Screentime (Windows)

Two supported installation stories. Both assume the same runtime shape:
`screentime-agent.exe` runs elevated (as a Windows service), one
`screentime-session.exe` per login session samples the desktop and talks to
the agent over the named pipe `\\.\pipe\screentime`, and the Tauri dashboard
(`Screentime`) is a plain per-user app that issues one-shot pipe commands.

---

## Story A — Manual / elevated install

This is the manual developer flow.

### 1. Build release binaries

From the repository root:

```powershell
cargo build --release -p st-agent -p st-session
```

Outputs land in `target\release\screentime-agent.exe` and `target\release\screentime-session.exe`.

### 2. Register the agent as a Windows service (elevation required)

```powershell
$fso = New-Object -ComObject Scripting.FileSystemObject
$short = $fso.GetFile('target\release\screentime-agent.exe').ShortPath

sc.exe create ScreentimeAgent type= own start= auto binPath= $short DisplayName= "Screentime Agent"
Set-ItemProperty HKLM:\SYSTEM\CurrentControlSet\Services\ScreentimeAgent -Name ImagePath -Value "$short --service" -Type ExpandString
sc.exe start ScreentimeAgent
```

### 3. Register the session helper for logon autostart (no elevation)

The helper writes itself into `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`:

```powershell
& "target\release\screentime-session.exe" --autostart on
```

## Story B — Bundled NSIS installer (Official)

This is the fully automated, zero-touch NSIS installer generated by Tauri v2. It packages all three binaries (UI, Agent, Session) into a single `.exe` setup file, handles service registration, auto-start, and seamless uninstallation via native NSIS hooks.

### Building the Installer

1. **Build the background binaries in release mode:**
   ```powershell
   cargo build --release -p st-agent -p st-session
   ```

2. **Copy the binaries into the Tauri bundle folder:**
   ```powershell
   Copy-Item target\release\screentime-agent.exe "ui\src-tauri\bin\"
   Copy-Item target\release\screentime-session.exe "ui\src-tauri\bin\"
   ```
   *(Note: The `ui/src-tauri/tauri.conf.json` is pre-configured to bundle any executables in the `bin/` directory into the final installer).*

3. **Build the Tauri installer:**
   ```powershell
   cd ui
   npm run tauri build
   ```

The final installer will be generated at `target\release\bundle\nsis\Screentime_0.1.0_x64-setup.exe`.

### How the Hooks Work
The `ui/src-tauri/installer_hooks.nsh` script is injected into the NSIS compilation. 
- **Post-install:** It automatically runs `--install` on the agent, starts the Windows Service `sc.exe start ScreentimeAgent`, and runs `--autostart on` for the session tracker.
- **UI Launch:** Because NSIS drops elevation when launching the UI at the end of the wizard, the UI safely spawns the session tracker directly in the active user's session during its Rust `setup` hook.
- **Pre-uninstall:** It cleanly stops the Windows service, uninstalls it, and removes the registry autostart keys.
